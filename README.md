# rebate

브랜드와 패키징 제작 업체를 연결하는 리베이트 UI 프로젝트입니다.

## 다른 컴퓨터에서 실행

Node.js 24를 설치한 뒤 저장소 폴더에서 실행합니다. Windows와 macOS에서 같은 명령을 사용합니다.

```sh
cd rebate-ui
npm ci
npm run dev
```

서비스 소개: http://127.0.0.1:5178/#intro

작업 시작 전 `git pull`, 작업을 마치면 커밋하고 `git push`합니다.

화면 구성과 Cloudflare 배포 설정은 [프로젝트 안내](rebate-ui/README.md)를 참고하세요.
