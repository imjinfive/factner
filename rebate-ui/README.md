# 팩트너 고객 사이트

브랜드와 박스·패키징·부자재 제작 업체를 연결하는 React + Vite 앱입니다. Motion으로 소개 화면과 조작 피드백을 구현합니다. kimkimco / kimkimdeck과 코드·설정을 공유하지 않는 독립 프로젝트입니다.

고객 사이트는 https://factner.com, 별도 관리자 사이트는 https://admin.factner.com 입니다. 두 사이트는 팩트너 전용 서버와 D1 데이터로 연결됩니다. 관리자 앱은 저장소 루트의 `admin-ui/`에 있습니다.

## 실행

Node.js 24 기준입니다. [루트 README](../README.md)에 따라 로컬 DB 마이그레이션, API와 관리자 서버를 먼저 준비하세요.

```sh
npm ci
npm run dev
```

실행 주소는 http://127.0.0.1:5178/ 입니다. `/api`는 로컬 Worker의 `127.0.0.1:8787`로 프록시합니다. 정적 미리보기만으로는 견적 접수나 업체 데이터를 사용할 수 없습니다.

```sh
npm test
npm run build
```

이 폴더의 테스트는 화면 모델 검사이며, 인증·업체·알림을 포함한 전체 검사는 저장소 루트에서 `npm test`로 실행합니다. 로컬 Turnstile 키는 루트의 `.dev.vars`에서 별도 설정합니다.

## 화면과 탐색

서비스 소개, 업체 검색·필터·정렬, 업체 상세·사진, 관심 업체, 최대 3곳 비교, 단계별 견적 요청, 나의 활동, 이용 안내, 멤버십 안내를 제공합니다. 운영 문서는 하단의 개인정보처리방침·이용약관에서 열 수 있습니다.

메뉴를 이동해도 주소는 `/`로 유지됩니다. 현재 화면을 브라우저 방문 기록에 저장해 새로고침과 뒤로·앞으로 이동을 지원합니다. 기존 `/#intro` 등의 링크도 해당 화면을 연 뒤 `/`로 정리합니다. 주소를 복사해 새 탭에서 열면 기본 업체 찾기 화면으로 시작합니다.

서비스 소개는 큰 글자와 여백, 미니어처 패키징 마을의 스크롤 확대, 세 종류의 사진이 모이는 업체 비교, 현장 확인, 직접 선택/견적 비교 전환, 초록 상자 언박싱 순서의 이야기입니다. 일반적인 카드 나열 화면으로 바꾸지 않습니다. 모바일과 움직임 줄이기 설정을 유지하세요.

이미지는 디자인 시안용 AI 이미지입니다. 같은 사진을 여러 업체·장면의 실제 자료처럼 반복하지 않습니다. [소개 이미지와 프롬프트](docs/service-images.md), [서로 다른 패키징 사진 구성](docs/packaging-photos-v2.md)에 제작 기록이 있습니다.

## 실제 업체와 예시 구분

`/api/suppliers`에서 관리자가 공개한 실제 업체를 불러옵니다. 업체 정보·사진 수정은 메인 데이터를 통해 반영됩니다. 페이지를 새로 열거나 업체 정보를 새로 불러오면 최신 내용을 확인합니다. 비공개·보관 업체와 사진은 공개 API로 볼 수 없습니다.

현재 실제 업체 등록은 완료되지 않았습니다. **테스트 모드이고 공개 업체가 없을 때만** 예시 업체를 보여줍니다. 서버 연결 실패 시 예시 데이터로 가장하지 않고 오류와 재시도 버튼을 표시합니다. 실제 업체에는 가상 평점·리뷰를 붙이지 않으며, 현장 검증 표시는 관리자가 실제 방문 기록과 사진을 갖춰 등록해야 합니다.

업체 사진 업로드는 관리자 기능입니다. JPG·PNG·WebP 한 장 1.5MB 이하, 업체당 8장까지 가능합니다. 고객 견적 파일 업로드와는 별개이며 고객은 HTTPS 참고 자료 링크를 사용합니다.

## 견적 접수와 운영 상태

담당자명·이메일·제작 조건을 입력하고 정보 수집 안내와 약관에 동의하면 서버에 접수합니다. 전화와 HTTPS 참고 링크는 선택입니다. 동의한 문서 버전을 서버에 기록하며 안내가 바뀌면 다시 확인해야 합니다. Cloudflare Turnstile 검증과 접수 횟수 제한을 적용합니다.

실패하면 입력을 유지하고 같은 접수 번호로 재시도해 중복 접수를 막습니다. 관리자에서 변경한 진행 상태와 고객 안내는 나의 활동에서 확인합니다. 내부 메모와 다른 고객 요청은 조회되지 않습니다. 접수 키와 관심 업체는 이 브라우저에만 저장되며 고객 로그인·기기 간 동기화 기능은 없습니다.

**현재는 테스트 접수입니다.** 운영 상호·문의 이메일·알림 수신 이메일과 실제 업체 자료를 확정해야 합니다. 개인정보처리방침·약관도 검토용 초안입니다. 가상 정보만 입력하세요. 관리자 본인의 비밀번호 변경·인증 앱 연결도 필요합니다.

새 견적·운영 오류 이메일의 대기열과 재시도는 구현했지만 수신 주소 인증·발송 연결 전에는 메일을 보내지 않습니다. 제작 업체 자동 입찰·고객 정보 자동 전달, 고객 파일 업로드, 실제 리뷰 등록, 결제·계약·유료 멤버십은 아직 제공하지 않습니다.

## 배포

저장소 루트에서 `npm run deploy:main`을 실행합니다. `rebate-ui/dist`를 팩트너 메인 Worker의 정적 자산으로 올리고 견적·업체 API와 함께 배포합니다. 관리자 사이트는 별도 Worker와 정적 자산으로 배포합니다. 마이그레이션·보안 비밀값·검증·복구 절차는 [루트 README](../README.md)와 [운영 안내](../docs/operations.md)를 참고하세요.
