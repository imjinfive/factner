# 팩트너 고객 사이트

브랜드와 패키징 제작 업체를 연결하는 React + Vite 앱입니다. 독립 프로젝트이며 kimkimco / kimkimdeck의 파일이나 설정을 사용하지 않습니다.

## 실행

Node.js 24 기준입니다. 저장소 루트 README에 따라 API와 관리자 서버를 함께 실행하세요.

```sh
npm ci
npm run dev
```

서비스 소개: http://127.0.0.1:5178/#intro

`/api` 요청은 로컬 API(`127.0.0.1:8787`)로 전달됩니다. 정적 미리보기만 실행하면 견적 접수는 동작하지 않습니다.

```sh
npm test
npm run build
```

## 화면

서비스 소개의 스크롤 연출과 직접 선택·견적 비교, 업체 검색·필터·정렬, 업체 상세·사진·리뷰, 관심 업체·최대 3곳 비교, 3단계 견적 요청, 활동 내역, 이용 안내와 멤버십 안내를 제공합니다.

견적 요청은 서버에 접수됩니다. 담당자명과 이메일은 필수, 전화와 참고 자료 HTTPS 링크는 선택입니다. 실패 시 입력을 유지하고 재시도할 수 있으며, 중복 클릭·네트워크 재시도는 동일 접수 번호로 처리합니다. 진행 상태와 운영팀 안내는 나의 활동에서 확인합니다. 접수 키는 이 브라우저에 저장되며 고객 로그인·기기 간 동기화 기능은 없습니다.

업체·리뷰·현장 확인 자료는 예시이고 AI 사진은 실제 방문 증빙이 아닙니다. 제작 업체에 자동 발송하거나 결제하지 않습니다. 서버의 운영 설정이 테스트 상태이면 가상 정보만 제출해야 합니다.

## 배포

루트의 `npm run deploy:main`을 사용합니다. `rebate-ui/dist`를 팩트너 메인 Worker의 정적 자산으로 올리고 견적 API와 함께 `factner.com`, `www.factner.com`에 연결합니다. 관리자 사이트는 별도 Worker와 별도 정적 자산으로 배포합니다. 상세 절차는 루트 README를 참고하세요.
