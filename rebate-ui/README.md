# 리베이트 UI

`kimkim_deck`과 파일, 의존성, 설정을 공유하지 않는 독립 React + Vite 프로젝트입니다.

## 실행

```sh
npm install
npm run dev
```

미리보기: http://127.0.0.1:5178

## 확인

```sh
npm test
npm run build
npm run preview
```

## 화면과 동작

- 서비스 소개: 흩어진 패키징 사진이 업체 비교로 정리되는 장면, 현장 확인, 직접 선택·비교 견적 전환, 고객의 첫 개봉 장면
- 업체 찾기: 검색, 카테고리, 현장 확인·소량 필터, 정렬
- 업체 상세: 제작 사례, 현장 확인 항목, 리뷰, 직접 매칭
- 관심 업체 저장, 최대 3곳 조건 비교
- 3단계 견적 요청 및 나의 활동
- 브랜드·제작업체 멤버십 구성안
- 반응형, 다크 모드, 키보드 조작, 동작 줄이기 지원

업체·리뷰·현장 확인 정보는 가상 데이터이며 이미지는 AI 생성 예시입니다. 실제 업체의 품질 또는 방문 사실을 나타내지 않습니다.

현재 UI 시제품으로 로그인, 실제 입찰 발송, 계약, 결제, 파일 업로드, 서버 저장은 없습니다. 관심 업체와 작성한 요청은 `localStorage`의 `rebate:favorites`, `rebate:requests`에만 저장됩니다. 브라우저 데이터를 삭제하면 사라집니다. 민감한 실제 고객 정보를 입력하지 마세요.

## Cloudflare 배포

정적 빌드이므로 Cloudflare Pages의 새 프로젝트에 독립적으로 연결할 수 있습니다.

- 프로젝트 루트: `rebate-ui`
- 빌드 명령: `npm run build`
- 출력 폴더: `dist`
- 별도 환경 변수 없음

또는 `npm run build` 후 `dist`를 Pages에 업로드할 수 있습니다. 해시 탐색을 사용하므로 별도 경로 재작성 규칙이 필요 없습니다. 이 작업에서는 실제 배포하지 않았습니다.

## 디자인

밝은 중립 배경과 초록색 포인트, 큰 여백, 종이 질감의 제품 이미지. Motion spring으로 버튼 눌림·찜·필터·대화상자에 즉각적인 피드백을 제공합니다. Toss의 간결한 흐름에서 영감을 받았으며 공식 Toss 디자인 시스템을 사용하거나 복제하지 않습니다.
