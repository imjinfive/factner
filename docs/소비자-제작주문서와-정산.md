**주문 확인 서명 문안**

“위 주문번호의 제작 사양과 도안 버전, 납기, 총 결제금액 및 취소·환불 조건을 확인했습니다. 위 조건으로 주식회사 킴킴컴퍼니에 제작을 주문합니다.” 결제 직전에 사양과 금액을 고칠 수 있게 한다. 신청과 회사의 승낙, 결제 승인 시각을 구분하고 승낙된 주문서 사본을 고객이 보관할 수 있게 전자문서로 교부한다.

**주문제작 철회 제한을 적용할 주문에서만 별도로 받을 문안**

별도 항목은 미리 선택하지 않는다. 구체적 사유가 없는 기성품에 표시하지 않는다. 거부했을 때 해당 개별제작 주문을 진행할 수 있는지 주문 전에 알린다. 주문별 고지 원문·도안 버전·선택·서명자·시각을 주문서와 연결한다. 회원가입 서명이나 업체 정산 버튼을 대신 사용하지 않는다.

## 2. 회사와 제작업체의 지급 약정

“회사는 발주서에 기재한 품목·수량·사양을 제작업체에 위탁하고, 공급가액·세액·합의 비용을 합한 대금을 지급합니다. 납품일, 검사 방법·기한, 보완 절차, 지급일을 착수 전에 확정합니다. 거래 완료 시 합의한 지급 경로로 정산하며, 고객의 미응답이나 구매확정 지연으로 약정 또는 법정 지급기일을 넘기지 않습니다. 이견이 생기면 회사는 해당 수량·사유·금액을 통지하고, 이견 없는 금액은 기한 내 지급합니다.”

주문별로 달력상의 최종 지급일을 적는다. 구매확정은 지급 지시 기준 중 하나로 사용하되 업체 지급의 유일한 조건으로 두지 않는다. 제조위탁에 하도급법 등이 적용되면 착수 전 서면 교부와 법정 지급기일을 우선 반영한다.

## 3. 첫 실결제 전에 확인할 사항

- 통신판매업 신고·공개정보, 호스팅 계약상 제공자, 대표 연락처와 실제 회신·반품 경로를 대조한다.
- 카드 가맹점·영수증·주문서·환불 주체를 회사의 직접판매 구조와 일치시킨다. PG에 고객→결제기관→회사 또는 제작업체의 실제 입금 경로를 서면으로 확인한다. 판매대금인지 타인 대금 정산인지, 결제대금예치·정산 대행 요건 및 금융업 등록 필요성을 국내 전자금융 전문 변호사와 확인한다.
- 회사의 판매 매출과 제작업체 공급대금, 세금계산서·현금영수증 발행주체를 세무 처리와 맞춘다.
- 실제 계약에 맞춰 배송·제조·결제 수탁자와 독립된 제3자 제공을 구분한다. Cloudflare 등 국외 수령자·처리국가·기간·법적 근거를 확인한다. 회원·반려 자료와 백업의 파기, 이용자 열람·삭제, 미성년 계약과 만 14세 미만 정보처리 방식을 실제 절차와 일치시킨다.
- 주문 직전 수정, 회사 승낙·사본 교부, 결제 취소·부분 취소, 배송 중 분쟁, 수취 후 하자, 구매자 미응답, 중복 지급 방지를 결제기관 테스트 환경에서 각각 확인한다. 공급자 지급 후에도 회사가 소비자 환불을 처리할 수 있어야 한다.
