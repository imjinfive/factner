# 회원 심사·마이페이지·발주

2026-10-27 변경된 회원·업체 통합, 사양 검토, 거래 연결 후 발주 절차는 [회원·업체 운영 순서](member-workflow.md)가 우선합니다. 아래는 이전 구현 기록입니다.

2026-10-21 구현. 기존 견적 조회 키와 관리자 계정을 유지하는 추가 기능입니다.

## 가입과 접근 권한

1. 브랜드 또는 제작 업체 선택.
2. 개인·개인사업자·법인사업자 선택.
3. 업체명, 담당자, 연락처, 이메일, 비밀번호 입력. 사업자는 10자리 등록번호와 등록증 첨부 필수.
4. 가입 신청은 대기 상태로 저장. 로그인 시 올바른 비밀번호를 입력하면 심사 상태와 안내 사유를 확인할 수 있지만 세션은 발급하지 않습니다.
5. 대표 관리자가 자료를 확인하고 승인하면 로그인 가능. 심사 결과와 처리자·시간 기록. 보류·중지는 안내 사유 필수.

관리자 메뉴의 ‘회원 관리’는 전체 회원을 기본으로 표시합니다. 업체명·담당자·이메일·연락처·사업자번호 검색과 활동/회원 유형 필터, 상태별 건수를 제공합니다. 회원 상세에서 가입 자료·상태 변경 기록·발주 현황을 확인하고 해당 회원의 발주 목록과 상세로 이동합니다. 승인된 회원의 이용 중지·재개는 기존 심사 API와 이력을 사용하며 발주 기록은 변경하지 않습니다. 회원 안내는 해당 회원에게 공개되는 내용이며 내부 메모가 아닙니다.

회원 검색·필터 확장은 2026-10-21 관리자 사이트에 반영했습니다. 당시 전체 테스트 42개와 관리자 Worker 번들 검증이 통과했으며, 운영 브라우저에서 검색·상태 필터·회원별 발주 조회·목록 복귀와 조건 유지를 확인했습니다. 이 검증에서는 운영 회원의 상태를 변경하지 않았습니다.

대표 관리자는 회원 상세에서 업체명·담당자·연락처를 수정할 수 있습니다. 변경 전후 값과 처리자·시간을 남기고 최근 50개 수정 기록을 보여줍니다. 로그인 이메일·비밀번호·활동 구분·회원 유형은 이 기능으로 바꾸지 않습니다. 일반 정보 수정은 기존 로그인과 확정 발주 사양을 유지하며, 동시에 수정한 이전 화면의 저장은 차단합니다.

가입 승인은 현장 검증 표시와 다릅니다. 등록번호는 형식만 검사하며 국세청 진위 조회나 실사 확인을 대신하지 않습니다. 개인 회원도 심사 후 이용합니다.

회원 쿠키는 관리자 쿠키와 분리되며 HttpOnly, SameSite=Strict, HTTPS에서 Secure를 사용합니다. 유효 기간은 8시간입니다. 중지·비밀번호 변경 시 세션이 무효화되고, 회원 버전 검사로 동시 발급된 과거 세션도 차단합니다. 쓰기 요청 출처, 로그인 횟수, 이메일별 가입 횟수, 파일 업로드 횟수를 검사합니다. 운영 Turnstile 연결은 회원가입에도 적용됩니다.

## 자료와 저장

- 가입 자료: 등록증 1개, 현장·제품 사진 최대 4개를 UI에서 선택. 서버 총 첨부 한도 5개.
- 내 패키징: 규격·소재·인쇄·후가공·상세 사양, 파일 최대 6개, 즐겨찾기. 최대 200개 활성 템플릿.
- 파일: JPG/PNG/WEBP/PDF, 파일당 1.5MB. 실제 파일 시그니처 검사. 사진 유형은 PDF 제외. 회원당 보관 파일 200개 한도.
- D1에 비공개 파일로 저장. 사업자등록증·가입 사진은 본인 및 대표 관리자만 접근. 제작 자료는 동의 후 해당 발주의 제작 업체와 운영 관리자만 접근.
- 파일은 새로 업로드하며 기존 내용 덮어쓰기·삭제 API를 제공하지 않습니다. 승인된 주문에서 참조하는 파일을 변경할 수 없습니다. PDF는 다운로드로 제공합니다.

현재는 실제 개인정보·기밀자료를 받지 않는 테스트 기능입니다. 수집 동의 버전과 테스트 확인을 서버에서 확인합니다. 정식 운영 전 자료별 보유·파기, 미사용 업로드 정리, 용량 확장, 계정 복구, 실제 업체 정보 제공 정책을 확정해야 합니다.

## 거래 업체 연결

대표 관리자의 ‘업체 매칭’에서 이용 중인 브랜드와 제작 업체를 검색해 연결합니다. 한 브랜드가 여러 제작 업체와 연결될 수 있으며, 양쪽 마이페이지에 상대 업체명·담당자·연락처가 표시됩니다. 가입 서류와 관리자 메모는 공유하지 않습니다. 이 연결은 발주 전달을 위한 관계 등록이며 법적 계약서 체결을 대신하지 않습니다.

매칭 등록·종료·재개는 이력을 남깁니다. 종료된 연결이나 이용 중지된 회원에게는 새 발주를 보낼 수 없습니다. 이미 접수된 발주와 최종 승인 기록은 유지됩니다.

## 견적·발주 입력

- 패키징 이름과 규격은 ‘직접 입력’ 안내가 있는 입력란입니다.
- 소재는 종이·골판지·플라스틱·천/부직포·목재, 인쇄와 후가공도 각각 5개 선택지를 제공합니다. 모두 직접 입력이 가능하며, 인쇄·후가공은 ‘없음’도 선택할 수 있습니다. 기존에 저장한 사용자 입력값은 유지합니다.
- 저장된 패키징과 지난 발주는 사양을 요약해 불러옵니다. 수량·희망 납기·배송지를 확인하고, 사양 변경이 있을 때만 펼쳐 수정합니다. 이전 가격은 참고용입니다.
- 배송지는 우편번호 찾기와 기본/상세 주소 입력을 제공합니다. 검색 버튼을 누를 때 카카오 우편번호 서비스를 불러오며, 연결에 실패해도 주소를 직접 입력할 수 있습니다. 기존 주소 문자열도 그대로 불러옵니다.
- 연락처와 사업자등록번호 입력 시 지원하는 국내 번호 형식에 맞춰 하이픈을 붙입니다. 이는 입력 편의 기능이며 번호의 진위 검증은 아닙니다.

## 발주 흐름

연결된 제작 업체를 선택하고 해당 발주의 사양·파일·수량·납기·배송지·요청 사항 전달에 동의하면, 발주는 관리자와 제작 업체에 함께 접수되어 ‘업체 확인 중’부터 시작합니다. 받을 수 있는 연결 업체가 하나면 그 업체를 표시하고, 여러 곳이면 브랜드가 선택합니다. ‘새 업체 매칭 요청’을 선택하면 아래의 매칭 대기 과정부터 진행합니다. 발주가 자동 전달되어도 금액·납기는 제작 업체의 답변과 브랜드의 최종 승인을 거칩니다.

| 상태 | 처리자 / 다음 작업 |
|---|---|
| 매칭 대기 | 관리자: 승인된 제작 업체 제안 |
| 업체 연결 확인 | 브랜드: 업체와 전달 항목 확인·동의 |
| 업체 확인 중 | 제작 업체: 총액·가능 납기·제작/결제 조건 제안 |
| 최종 승인 대기 | 브랜드: 조건 승인 또는 재확인 요청 |
| 발주 확정 | 제작 업체: 제작 시작 |
| 제작 중 | 제작 업체: 배송 업체·운송장 또는 전달 내역 기록 |
| 출고 | 브랜드: 입고 확인 |
| 입고 완료 | 과거 사양으로 새 요청 가능 |

총 견적은 부가세·배송비를 포함한 원화 총액입니다. 확정 전 브랜드/관리자가 사유와 함께 요청을 취소할 수 있습니다. 확정 후 자동 취소·조건 변경은 제공하지 않고 문의 기록으로 운영팀과 조정합니다. 이 기록만으로 확정 조건이 바뀌지는 않습니다.

견적 수정·승인·매칭·메시지·제작/출고/입고는 변경 기록을 남깁니다. 버전 비교로 이전 화면에서 다른 변경을 덮어쓰는 것을 막습니다. 최종 승인 스냅샷은 별도 저장하며, 재요청은 새 ID로 생성하고 기존 견적과 승인을 승계하지 않습니다. 요청 ID를 재전송해도 중복 주문을 만들지 않습니다.

초기에는 기존 익명 견적 접수와 회원 발주가 별개입니다. 기존 견적은 마이페이지의 ‘기존 견적 조회’에서 계속 확인합니다. 수신 이메일 인증, 비밀번호 분실 자동 복구, 결제·정산, 배송사 자동 추적, 별도 납기 변경 승인 절차, 조건에 따른 업체 자동 선정·자동 메일 발송은 미구현입니다.

## 제작 업체 발주 알림과 응답 관리

발주가 제작 업체에 실제 전달된 시점부터 확인 여부와 답변 대기를 서버에 기록합니다. 관리자 매칭 제안만 있고 브랜드가 자료 전달에 동의하지 않은 발주는 제작 업체 알림에 포함하지 않습니다.

- 미확인: 제작 업체가 아직 발주 상세를 열지 않은 요청입니다. 목록 조회·알림 열기·관리자 확인은 읽음 처리하지 않습니다.
- 답변 대기: 제작 업체에 전달됐지만 견적 답변이 없는 요청입니다. 단순 열람이나 문의 메시지는 견적 답변을 대신하지 않습니다.

- 브랜드가 조건 재확인을 요청하면 새 응답 대기로 보고 알림과 기한을 다시 시작합니다. 취소·견적 답변 이후에는 해당 대기 알림을 해제합니다.
