# 익명 후보 중심 개편

2026년 10월 24일 요청 기준.

## 이번에 바꾼 것

- 새 방문과 새로고침은 서비스 소개에서 시작한다. 앱 안의 뒤로/앞으로 이동은 유지하며, 폐지된 업체찾기·멤버십 주소는 소개로 보낸다.
- 견적 문의는 브랜드/제작 업체, 품목, 희망 지역을 선택한다. 제작 업체만 월 제작 가능 수량을 추가한다.
- 가상 후보를 조건에 맞게 선별해 A업체 또는 A브랜드 등으로 보여준다. 해당 조건의 예시가 없으면 빈 결과를 보여주며 임의로 다른 조건의 후보를 채우지 않는다.
- 후보 선택 후 직접 가입 또는 담당자 연결로 나눈다. 직접 가입은 역할을 미리 선택한 기존 가입 심사로 연결한다. 선택 조건은 가입 화면 위에서 확인하고 후보로 돌아갈 수 있다.
- 상담 신청은 화면 미리보기이며 전송하지 않는다. 결제 수단은 선택할 수 있지만 금액·과금 조건 미확정 상태여서 결제 정보를 받거나 청구하지 않는다.
- 공개 업체 목록·사진 API를 차단했다. 관리자 자료와 기존 회원 간 연결·발주·알림은 유지한다. 데이터베이스 변경이나 자료 삭제는 없다.
- 기존 견적은 하단의 기존 견적 조회와 마이페이지에서 계속 확인한다. 공개 업체 즐겨찾기는 화면에서 제거했다.

## 실제 운영 전에 결정할 것

1. 간단한 조건으로는 후보 제안까지만 가능하다. 실제 견적 전 수량, 규격, 소재, 납기, 창고 위치를 확인해야 한다. 주소를 아직 받지 않았으므로 정확한 창고 거리를 표시하지 않는다.
2. 가입 심사, 유료 서비스 신청, 양측 거래 계약은 별개다. 매칭 이용료의 금액과 지급 시점, 제공 범위, 미성사 시 처리를 먼저 결정한다.
3. 제작 업체에게 보여줄 브랜드는 현재 업체를 찾고 있으며 정보 제공에 동의한 유효한 수요여야 한다. 단순 가입 회원 수를 수주 가능한 기회로 표시하지 않는다.
4. 익명 후보를 제안하는 것과 실명·연락처가 보이는 거래 연결을 구분한다. 기존 관리자 업체 매칭 기능은 후자다. 아직 검토 중인 후보에 사용하면 안 된다.
5. 담당자 연결 접수·알림과 선택 조건의 서버 저장은 후속 작업이다. 이번 예시 후보 선택은 관리자에 실제 매칭으로 등록되지 않는다.

## 관리자 화면의 다음 변경

- 유지: 회원 심사·정보 수정, 업체 역량·현장 자료, 실제 거래 매칭, 발주·납기·미확인 알림, 기존 견적 기록.
- 수정: 업체 관리의 공개/비공개를 매칭 후보 사용/중단으로 바꾸고, 공개 목록을 전제로 한 안내와 운영 준비 항목을 정리한다. 상태 값과 저장된 기록은 이관 계획 없이 삭제하지 않는다.
- 추가: 상담 대기 → 조건 확인 → 익명 후보 제안 → 양측 의사 확인 → 실제 거래 연결의 진행 관리. 가입과 유료 서비스 상태를 따로 기록한다.
- 확인: 현재 업체 자료와 제작 업체 회원은 별도 테이블이다. 실제 후보 선정 시 어느 승인 회원과 연결되는지 관계를 명확히 해야 한다.
- 별도 멤버십 관리 메뉴나 결제 운영 기능은 현재 없다. 존재하지 않는 관리자 기능을 삭제한 것으로 보고하지 않는다.

## 검증

품목·지역·생산량 필터, 잘못된 입력과 빈 결과, 후보 익명성, 폐지 경로, 공개 업체 API 차단, 기존 회원·발주 권한 검증을 포함한 자동 테스트 67개와 빌드를 통과했다. 브라우저에서 가입/상담/결제 시안과 모바일, 후보 선택 유지, 기존 견적 빈 화면을 확인했다.

2026년 10월 24일 factner.com과 admin.factner.com의 테스트 버전에 반영했다. 실제 주소에서 새 화면, 공개 업체 조회 차단, 검색 제외 설정 유지를 확인했다. 데이터베이스 변경과 실제 결제는 없다.
